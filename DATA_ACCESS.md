# Data access

No data are distributed in this repository. The 30-min zone-level portal export, the corrected hospital-level 30-min series, the de-identified monthly
invoice summary and the intermediate result files are available from the corresponding author (teerawat.kae@crru.ac.th) on reasonable request, subject to the approval of
the hospital that owns the data. Utility invoices and account identifiers are not shared.

Place the hospital-level series and the invoice summary in `data/` and the result files in `results/` to run the code as described in `README.md`.
